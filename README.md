# DBHE
# [Deep Binary Hyperbolic Embedding for Large-scale Image Retrieval](https://www.sciencedirect.com/science/article/pii/S0925231225020831)
This paper is accepted for publication with Neurocomputing. lf you have any questions please contact zmr6445@163.com.

### Start

After the dataset has been prepared, we could run the follow command to train.
> python train.py

### Dependencies
We use python to build our code, you need to install those package to run
+ Python 3.8
+ Pytorch 2.3.1
+ torchvision 0.18.1
+ CUDA 11.8

### Training

Before training, you need to download the MIRFLICKR-25K dataset from https://press.liacs.nl/mirflickr/mirdownload.html, NUS-WIDE dataset from https://opendatalab.org.cn/OpenDataLab/NUS-WIDE and MS COCO dataset from https://cocodataset.org/.
